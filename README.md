# PixelQuest - GitHub Üzerinden APK Üretme Rehberi

## Adım Adım APK Üretme (GitHub Actions ile):
1. Bu ZIP dosyasının içindeki `www/` klasörünü, `config.xml` ve `package.json` dosyalarını GitHub reponuza yükleyin.
2. GitHub üzerinde `Add file -> Create new file` diyerek yolunu `.github/workflows/build-apk.yml` yapın ve workflow kodunu yapıştırıp kaydedin.
3. `Actions` sekmesinden APK'nızı indirin!
