# PixelQuest - GitHub Üzerinden APK Üretme Rehberi

1. Bu ZIP dosyasının içindeki `www/`, `res/`, `config.xml` ve `package.json` dosyalarını GitHub reponuza yükleyin.
2. GitHub üzerinde `Add file -> Create new file` diyerek yolunu `.github/workflows/build-apk.yml` yapın ve aşağıda verilen güncel workflow kodunu yapıştırıp kaydedin.
3. `Actions` sekmesinden APK'nızı indirin!
